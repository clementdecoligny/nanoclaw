## Routines rouleau + étirements (à appliquer systématiquement)

**Routine A — Post vélo / post run (10-12 min)**
Rouleau (45-60s par zone par jambe, lent) : quads VL → quads VMO → IT band → ischios → mollets
Étirements statiques 30s/côté : quad debout → hip flexor (fente basse) → fessier (figure 4)

**Routine B — Post renfo (5 min)**
Rouleau quads 45s/jambe + étirement quad 2×30s + IT band stretch 30s/côté

**Routine C — Soir jours de repos (5 min, optionnel)**
Rouleau léger quads + IT band, 45s/côté

Technique rouleau (EPP 500 Hard) : vitesse max 5 cm/s — pause 20-30s sur les nœuds douloureux jusqu'à diminution de moitié
