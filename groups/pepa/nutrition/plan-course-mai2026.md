## Lundi 18 + Mardi 19 mai — Plano Diario

| Heure | Repas | Contenu |
|---|---|---|
| 08:00 | Petit-déj | 250g iogurte grego ligeiro + 1 fruit + 40/80g granola (suave/intenso) + 1g vit. C |
| 11:00 | Milieu matinée | 1 iogurte proteico (~20g prot.) + 20g frutos oleaginosos OU 1 banane (suave/intenso) |
| 14:00 | Déjeuner | Sopa **s/batata** + légumes + 100g viande/poisson + 150/250g guarnição + léguminosas + 1 fruit |
| 17:00 | Goûter | 1 iogurte magro ou 1 babybel light + 1 fruit (échanger avec 11h si entraînement l'après-midi) |
| 19:30 | Dîner | Sopa **s/batata** + légumes + 100g viande/poisson + 120/180g guarnição + léguminosas + 1 fruit + oméga-3 ×2 + créatine 3g |
| Avant coucher | | 2 gélules bisciglinato de magnésio (30 min avant) |

## Mercredi 20 + Jeudi 21 mai — Plano Recarga Competição

| Heure | Repas | Contenu |
|---|---|---|
| 08:00 | Petit-déj | 250g iogurte grego ligeiro + 1 fruit + 90g cereais |
| 11:00 | Milieu matinée | 1 iogurte proteico (~20g prot.) + 1 fruit |
| 14:00 | Déjeuner | Sopa passada + 100g viande/poisson + **300g** riz/pasta + 1 fruit |
| 17:00 | Goûter | ~120g pain avec compota/marmelada/mel + 1 sumo de fruta coado/compal |
| 19:30 | Dîner | Sopa passada + 100g viande/poisson + **300g** riz/pasta + 1 fruit + oméga-3 ×2 + créatine 3g |
| Jeudi seulement 23:00 | Ceia | 1 banane |
| Avant coucher | | 1 gélule tart cherry + 2 gélules magnésio |

> ⚠️ Mer/Jeu : soupe doit être **passada** (mixée). Quantité riz/pasta = 300g par repas principal (charge glucidique).

---

## Suppléments à confirmer en stock
- Vitamina C 1g
- Oméga-3 (IFOS) — 2 gélules/dîner
- Créatine Creapure 3g/dîner
- Bisciglinato de magnésio
- Tart cherry (mer/jeu uniquement)

## Aliments manquants à acheter
- Iogurte proteico (~20g prot.) × 4 jours
- Iogurte magro ou babybel light (lun/mar 17h)
- Compota ou marmelada (mer/jeu 17h)
- Sumo de fruta coado ou Compal (mer/jeu 17h)
- Sopa passada (mer/jeu) — vérifier si soupe congélo est mixée
