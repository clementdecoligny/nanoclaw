# Décongélation panados de frango

Ne jamais sortir les panados de frango (escalopes panées) du congélateur à l'avance dans la journée. Ils décongèlent très vite au micro-ondes : décongeler juste avant cuisson, pas des heures en avance.

Signalé par Clément le 20/09/2026, après une action item de briefing suggérant de les sortir le matin pour le soir.
