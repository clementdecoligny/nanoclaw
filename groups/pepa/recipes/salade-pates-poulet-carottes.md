## Ingrédients (4–5 portions)

| Ingrédient | Quantité | Notes |
|---|---|---|
| Pâtes courtes (fusilli ou penne) | 350 g sec | Formes courtes — tiennent mieux en salade |
| Poulet rôti effiloché (restes) | ~250–300 g | |
| Carottes | 2 | Râpées |
| Concombre | ½ | En petits dés |
| Poivron rouge | 1 | Émincé fin |
| Raisins secs | 30 g | Uva Passa — sucré, classique avec carotte |
| Graines de tournesol | 2 c. à soupe | Pour le croquant |
| Persil frais | 2 c. à soupe | Haché |
| Huile d'olive | 4 c. à soupe | |
| Jus de citron vert | 1–2 | |
| Sel, poivre | | |

---

## Méthode

1. Cuire les pâtes al dente. Égoutter, rincer à l'eau froide, laisser refroidir.
2. Râper les carottes. Émincer le poivron et couper le concombre en petits dés.
3. Dans un grand tupperware, mélanger pâtes froides + poulet effiloché + carottes + concombre + poivron + raisins secs + graines de tournesol.
4. Préparer la vinaigrette : huile d'olive + jus de citron vert + sel + poivre. Verser sur la salade, mélanger.
5. Ajouter le persil haché juste avant de fermer le tupperware.
6. Transporter au frais (sac isotherme si possible). Sortir 10 min avant de servir.

---

## Distribution par âge

- **Adultes** : version complète
- **M / G** : servir une portion à part avant d'ajouter le citron vert si sensibles à l'acide
- **Bébé** : pâtes + poulet émietté fin + carotte râpée très fine, sans vinaigrette

---

## Conservation

- Frigo : 24h (sans vinaigrette ajoutée à la dernière minute, tient mieux)
- Ne se congèle pas (légumes crus + pâtes)

---

## Notes

- Variante possible : remplacer les raisins secs par des figues fraîches coupées en petits morceaux (stock actuel disponible)
