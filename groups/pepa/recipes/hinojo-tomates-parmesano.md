# Hinojo al horno con tomates y parmesano

**Source**: Libro de cocina (enviado por Clément)
**Prep time**: 10 min
**Cook time**: 30 min
**Total**: 40 min
**Serves**: 4 (entrante)
**Effort**: Muy bajo
**Batch-friendly**: Sí — se puede preparar antes y servir templado
**Age-appropriate**: Adults + M. G a intentar.
**Family verdict**: Por probar

---

## Ingredientes (4 personas, entrante)

| Ingrediente | Cantidad | Notas |
|---|---|---|
| Bulbos de hinojo | varios | Cortados de arriba abajo en rodajas gruesas |
| Tomillo fresco | al gusto | |
| Zumo de limón | al gusto | |
| Aceite de oliva | 4 tbsp + un poco más | |
| Tomates cherry | 1 bandeja | |
| Vinagre | al gusto | (tipo balsámico o de vino) |
| Azúcar | 1 pizca | |
| Parmesano rallado | 70 g | |
| Hojas de albahaca | 1 puñado | |
| Pan crujiente caliente | para servir | |

---

## Método

1. Precalentar el horno a **200°C**.
2. Cortar los bulbos de hinojo de arriba abajo en rodajas gruesas.
3. Colocar en una bandeja para hornear con el tomillo. Rociar con zumo de limón y 4 tbsp de aceite de oliva. Cubrir con papel de aluminio.
4. En otra bandeja más pequeña: colocar los tomates cherry. Rociar con vinagre + el resto del aceite de oliva. Espolvorear con azúcar. Cubrir con papel de aluminio.
5. Meter ambas bandejas al horno. Hornear **30 min** o hasta que el hinojo esté tierno y los tomates empiecen a reventar.
6. **Montaje**: Disponer en capas el hinojo, los tomates y el parmesano rallado con las hojas de albahaca. Verter los líquidos de cocción por encima.
7. Servir con pan crujiente caliente.

---

## Age branching

| | Adaptación |
|---|---|
| Adults | Versión completa |
| M (4.5y) | Tomates + parmesano, sin hinojo si no le gusta |
| G (2.5y) | Tomates muy cocidos + pan |
| Baby | No apto |

---

## Notas
- Los líquidos de cocción son el "aliño" — no tirar
- Perfecto como entrante o acompañamiento del pollo o pescado
- Hinojo: añadir a la lista de la compra semanal
