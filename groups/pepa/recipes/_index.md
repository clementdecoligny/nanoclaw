## Batch Cooking Chains

These recipe pairs share a base component — one cook session feeds two meals:

- **Ragu → Cannelloni**: Make a large ragu batch → pasta + baked cannelloni 2 days later
- **Pollo chipotle → Pad Thai**: Batch chicken → Mexican night + Asian night
- **Lentilles → Ensalada**: Cook lentils in bulk → warm salad + cold lentil salad for lunch
- **Soupe légumes → Bébé purée**: Family soup base doubles as baby puree (blend before seasoning)
- **Pizza dough**: Freeze extra dough balls → quick pizza night later in the week
