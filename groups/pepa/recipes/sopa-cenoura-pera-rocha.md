# Sopa de Cenoura e Pêra Rocha

**Source**: Cookidoo / Bimby (r499549)
**Prep time**: 10 min
**Cook time**: 50 min (Bimby) / ~45 min (fogão)
**Total**: ~60 min
**Serves**: 6
**Effort**: Muito baixo
**Batch-friendly**: Sim — congela muito bem. Fazer grande quantidade.
**Age-appropriate**: Família toda ✅ incluindo bebé (sem sal para ela)
**Family verdict**: ❤️❤️❤️

---

## Porquê esta receita para esta família
- Sopa ao almoço e jantar = regra do plano nutricional do Clément ✓
- Pêra Rocha é portuguesa — perfeita com as entregas semanais de fruta
- Doce e suave → crianças adoram (G incluído)
- Congela perfeitamente → batch cooking ideal
- Bebé: versão sem sal, triturada fina ✓

---

## Ingredientes (6 doses)

| Ingrediente | Quantidade | Notas |
|---|---|---|
| Azeite | 20 g | |
| Cebola | 200 g | Cortada em pedaços |
| Alho | 2 dentes | |
| Cenoura | 150 g | Cortada em pedaços |
| Batata | 300 g | Cortada em pedaços |
| Pêra Rocha | 400 g | Cortada em cubos pequenos |
| Sal | 2 tsp | Reduzir ou omitir para porção do bebé |
| Tomilho fresco | 4 ramos | Só as folhas |
| Mostarda de Dijon | 15 g (1 tbsp) | Segredo da receita — não saltar |
| Água | 600 g | |
| Caldo de legumes | 1 tsp | Caseiro ou cubo |
| Noz-moscada | ¼ tsp | |
| **Para servir** | | |
| Crème fraîche ou natas | 1 tsp por prato | Opcional |
| Piri-piri em flocos | 1 pitada | Opcional (só adultos) |

---

## Método Bimby (TM5/TM6/TM7)

1. Colocar no copo o **azeite + cebola + alho** → refogar **12 min / Varoma / vel 1**
2. Adicionar **cenoura + batata + pêra + 1 tsp sal** → refogar **5 min / Varoma / vel 1**
3. Adicionar **tomilho + mostarda + água + 1 tsp sal + caldo + noz-moscada** → cozer **30 min / 100°C / vel 1**
4. Triturar **1 min / vel 5→7** (aumentar progressivamente)
5. Servir com 1 tsp crème fraîche + pitada de piri-piri

## Método fogão (sem Bimby)

1. Refogar cebola + alho em azeite a lume médio **10 min** até amolecer.
2. Adicionar cenoura + batata + pêra + sal. Refogar **5 min**.
3. Adicionar tomilho + mostarda + água + caldo + noz-moscada. Tapar, cozer a lume brando **30 min** até tudo macio.
4. Triturar com varinha mágica até textura cremosa. Ajustar sal.
5. Servir com crème fraîche + piri-piri.

---

## Estratégia batch
- Fazer **dobro ou triplo** da receita quando as pêras estão maduras
- Congelar em doses individuais (300–400 ml por tupperware)
- Clément: esta sopa conta como a sopa do almoço/jantar do plano nutricional ✓

---

## Age branching

| | Adaptação |
|---|---|
| Adults | Versão completa com crème fraîche + piri-piri |
| M (4.5y) | Sopa normal, sem piri-piri |
| G (2.5y) | Idem — textura suave, ele vai adorar (é doce) |
| Bebé | Reservar porção **antes de adicionar sal**, triturar fina |

---

## Notas
- A **mostarda de Dijon** é o segredo — dá profundidade sem sabor a mostarda pronunciado
- Pêra Rocha pode ser substituída por pêra normal ou até maçã
- Excelente sopa de inverno e primavera
- Quando as pêras da entrega estiverem muito maduras → fazer esta sopa imediatamente
