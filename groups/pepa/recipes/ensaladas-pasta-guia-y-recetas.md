# Ensaladas de pasta — guía + recetas seleccionadas

**Source**: directoalpaladar.com
**Effort**: Faible (cuisson pâtes + assemblage)
**Batch-friendly**: Oui — sans vinaigrette ni tomates crues → 2 jours frigo. Avec vinaigrette : max 2h.
**Age-appropriate**: Adults + M. G selon version.
**Family verdict**: ❤️❤️❤️ (style de cuisine qu'on veut développer)

---

## Règles générales pour une bonne salade de pâtes

1. **Pâtes courtes et ridées** : fusilli, penne rigate, rigatoni. Pas de pâtes fraîches (trop molles froides).
2. **Al dente** : les pâtes se raffermissent en refroidissant — légèrement sous-cuire est OK.
3. **Rincer à l'eau froide** est autorisé pour les salades (contrairement aux pâtes chaudes).
4. **Légumes cuits > légumes crus** si préparé en avance (tiennent mieux).
5. **Pas de tomates mûres** si préparé la veille (rendent de l'eau).
6. **Vinaigrette** : laisser reposer 2h max avec les pâtes pour qu'elles absorbent les saveurs.
7. **Servir à température ambiante** : sortir du frigo 10–15 min avant.

## Recettes sélectionnées (filtrées pour cette famille)

---

### A. Fusilli + mozzarella + thon + olives
_La classique méditerranéenne — 20 min_

**Serves** : 2 | **Effort** : très faible

| Ingrédient | Quantité |
|---|---|
| Fusilli | 160 g |
| Thon en boîte | 1 boîte |
| Mozzarella di bufala | 125 g |
| Tomates cerises | 12 |
| Basilic frais | 8 feuilles |
| Olives noires dénoyautées | 16 |
| Ail | 1 gousse |
| Huile d'olive, sel | à goût |

**Méthode** : Cuire fusilli, égoutter, rincer à l'eau froide. Couper tomates en deux. Écraser ail avec basilic + huile d'olive → sauce. Mélanger sauce + pâtes + tomates. Topper avec mozzarella en dés, thon, olives.

**Kids** : M → version nature (pâtes + mozzarella + thon à part). G → pâtes + thon nature.

---

### B. Pâtes + crevettes + poivron rôti + tomates séchées
_Méditerranéenne avec fruits de mer — 30 min_

**Serves** : 2 | **Effort** : faible

| Ingrédient | Quantité | Notes |
|---|---|---|
| Pâtes courtes | 200 g | |
| Crevettes cuites épluchées | 120 g | En stock congélateur ✅ |
| Poivron (rouge ou vert) | 1 | Rôti à la poêle 20 min |
| Oignon blanc | ½ | Finement haché |
| Tomates séchées | 50 g | Ponti Pomodori Secchi en stock ✅ |
| Huile d'olive, sel, poivre | à goût | |

**Méthode** : Cuire pâtes, égoutter, refroidir. Rôtir poivron en lamines à feu moyen 20 min. Hacher oignon et tomates séchées. Assembler tout. Réfrigérer 30 min. Assaisonner avant de servir froid.

**Kids** : M → pâtes + crevettes + poivron à part. G → pâtes + crevettes nature.

### C. Pâtes + saumon + sauce aneth légère
_Simple, élégante — 20 min_

**Serves** : 2 | **Effort** : très faible

| Ingrédient | Quantité | Notes |
|---|---|---|
| Pâtes courtes | 150 g | |
| Saumon frais | 150 g | Ou saumon fumé (plus rapide) |
| Olives noires | 12 | |
| Mayonnaise | 2 tbsp | |
| Lait | un peu | Pour détendre la mayo |
| Aneth frais | 1 brin | |

**Méthode** : Cuire pâtes, égoutter. Si saumon frais : cuire en dés à la poêle sans matière grasse. Disposer pâtes + saumon + olives. Mélanger mayo + lait + aneth haché → sauce légère. Napper au moment de servir.

**Kids** : M → pâtes + saumon + un peu de sauce à part. G → pâtes + saumon nature.

### D. Pâtes + poisson fumé + haricots verts + pommes de terre
_Version picnic/parc — 30 min_

**Serves** : 2 | **Effort** : faible

| Ingrédient | Quantité | Notes |
|---|---|---|
| Pâtes courtes | 250 g | |
| Haricots verts | 150 g | Ou judía verde en conserve ✅ |
| Pommes de terre cuites | 150 g | |
| Poisson fumé | 150 g | Saumon fumé + truite fumée recommandés |
| Huile d'olive | à goût | |
| Aneth ou coriandre haché | à goût | |
| Sel | à goût | |

**Méthode** : Cuire et refroidir pommes de terre → couper en cubes. Cuire haricots verts 5–10 min, égoutter. Cuire pâtes al dente, rincer à l'eau froide. Mélanger pâtes + pommes de terre + haricots. Assaisonner huile d'olive + sel. Disposer poisson fumé en lamelles par-dessus. Parsemer herbes.

**Règle panier du dimanche** : Tout préparer samedi soir. Poisson fumé en lamelles au moment de servir.
**Kids** : M → pâtes + poisson + haricots séparés. G → pâtes + poisson nature.

## Notes famille
