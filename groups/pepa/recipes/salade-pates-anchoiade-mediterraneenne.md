# Salade de pâtes à l'anchoïade méditerranéenne

**Total** : 20 min (assemblage)
**Serves** : 4–6

---

## Ingrédients

### Salade
| Ingrédient | Quantité | Notes |
|---|---|---|
| Pâtes courtes cuites | 400–500g | Fusilli, penne, farfalle |
| Tomates fraîches | 3–4 | En dés, ou tomates cerises coupées |
| Avocat | 1 | En cubes — ajouter en dernier |
| Feta | 100g | Émiettée |
| Olives noires dénoyautées | 60g | |
| Salade verte | 1 poignée | Optionnel, feuilles déchirées |
| Parmesan | 30g | En copeaux au péler-légumes |
| Basilic frais | 6–8 feuilles | ⭐ Fortement recommandé — à acheter |

### Vinaigrette à l'anchoïade
| Ingrédient | Quantité | Notes |
|---|---|---|
| Anchois (filets) | 3–4 filets | Pitéu en azeite — rincer légèrement |
| Ail | 1 gousse | |
| Citron | ½ (jus + zeste) | |
| Huile d'olive | 4 tbsp | |
| Poivre noir | à goût | Sel : les anchois salent, goûter avant |

---

## Méthode

### Vinaigrette (à faire en premier)
1. Écraser les filets d'anchois avec le plat du couteau jusqu'à obtenir une pâte.
2. Râper l'ail finement par-dessus.
3. Ajouter jus + zeste de citron. Fouetter en ajoutant l'huile d'olive → émulsion légère.
4. Goûter : sel si nécessaire (anchois salent beaucoup), poivre.

### Assemblage
5. Mélanger pâtes + vinaigrette dans un grand saladier. Laisser reposer 10–15 min (les pâtes absorbent les saveurs).
6. Ajouter tomates, olives, feta émiettée, salade verte. Mélanger délicatement.
7. **En dernier** : avocat en cubes (citron pour éviter l'oxydation).
8. Finir avec copeaux parmesan + feuilles basilic entières.

---

## Transport chez des amis

- Pâtes + vinaigrette : mélanger à la maison → transporter dans saladier fermé
- Avocat : couper sur place + quelques gouttes citron
- Basilic : feuilles entières dans un sac humide → déchirer sur place
- Parmesan : apporter le morceau + péler-légumes

---

## Notes

- Le secret est la vinaigrette anchoïade : umami + acide. Même les gens qui « n'aiment pas les anchois » l'adorent — ça ne goûte pas le poisson, juste le sel et la profondeur.
- Ne pas saler les pâtes lors de l'assemblage — toujours goûter d'abord.
- Variante : ajouter câpres (1 tbsp) pour plus d'acidité.
