# Salade de riz au thon et aux œufs durs

**Source**: Cuisine Actuelle (cuisineactuelle.fr)
**Prep time**: 15 min
**Cook time**: 20 min (riz + œufs) + 1h repos
**Total**: ~35 min + 1h repos froid
**Serves**: 4
**Effort**: Très bas
**Batch-friendly**: Oui ⭐⭐⭐ — se prépare la veille, meilleure le lendemain
**Age-appropriate**: Toute la famille ✅
**Family verdict**: Par essayer

---

## Pourquoi ça marche pour cette famille
- Riz toujours cuit en stock ✅ → gain de temps considérable
- Thon en conserve (à vérifier/acheter)
- Parfait pour le parc, pique-nique, repas d'été
- Très adaptable selon ce qu'il y a dans le frigo
- Clément : portion généreuse de riz ✓

---

## Ingrédients (4 personnes)

| Ingrédient | Quantité | Notes |
|---|---|---|
| Riz cuit | ~400g | Déjà en stock ✅ |
| Thon en conserve | 280g (1 grande boîte) | Égoutté |
| Œufs durs | 4 | 10 min d'ébullition |
| Tomates | 4–5 moyennes | En dés |
| Maïs en conserve | 140g | Égoutté (optionnel) |
| Cornichons | ~20 | En rondelles |
| Olives noires ou vertes | ~20 | |
| Mayonnaise | 3 tbsp | |
| Moutarde de Dijon | 1 tbsp | |
| Vinaigre (blanc ou cidre) | 1 tbsp | |
| Sel, poivre | à goût | |
| Filet d'huile d'olive | 1 tbsp | |

---

## Méthode

1. Cuire les œufs **10 min** dans l'eau bouillante. Refroidir immédiatement dans l'eau froide. Écaler et couper en quartiers.
2. Si riz pas déjà cuit : cuire selon les instructions, bien égoutter, laisser refroidir complètement.
3. Dans un grand saladier : mélanger riz + thon égoutté + maïs + tomates en dés + cornichons + olives.
4. **Sauce** : mélanger mayonnaise + moutarde + vinaigre + sel + poivre. Ajouter à la salade.
5. Ajouter un filet d'huile d'olive. Bien mélanger.
6. Ajouter les œufs durs par-dessus (ne pas trop mélanger pour qu'ils restent entiers).
7. Couvrir et réfrigérer **minimum 1 heure** avant de servir.

---

## Age branching

| | Adaptation |
|---|---|
| Adults | Version complète |
| M (4.5y) | Riz + thon + œuf + tomate, sans cornichons ni olives |
| G (2.5y) | Riz + thon + un peu d'œuf, sans sauce |
| Baby | Riz très cuit + thon émietté sans sel, sans sauce |

---

## Notes
- Se conserve **2 jours** au frigo (sans les œufs si possible — les ajouter au moment de servir)
- Parfait pour le lendemain midi avec le riz déjà prêt
- Variantes : ajouter poivron rouge, avocat (au moment de servir), feta
- Clément : doubler la portion de riz pour atteindre les objectifs glucidiques
