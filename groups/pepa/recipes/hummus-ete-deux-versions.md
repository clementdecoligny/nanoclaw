# Hummus été — 2 versions

**Source**: beingbiotiful.com
**Prep time**: 10 min
**Cook time**: 20–25 min (légumes rôtis)
**Total**: ~35 min
**Serves**: 4 (en entrée / dip)
**Effort**: Faible
**Batch-friendly**: Oui — hummus se conserve 4–5 jours au frigo
**Age-appropriate**: Toute la famille ✅ (enfants adorent le hummus)
**Family verdict**: ❤️❤️❤️

---

## Pourquoi ça marche pour cette famille
- Haricots blancs + pois chiches en stock ✅
- Alcachofas congelées en stock ✅ (pour version 1)
- Asperges blanches en conserve ✅ (pour version 2)
- Tahini = à avoir en stock (base de nombreuses recettes)
- Parfait en entrée, dip apéro, ou accompagnement
- Enfants adorent tremper du pain dedans
- Composant batch réutilisable toute la semaine

---

## VERSION 1 : Hummus artichauts + tomates confites + nori

### Ingrédients
| Ingrédient | Quantité | Notes |
|---|---|---|
| Haricots blancs cuits | 160 g | Hacendado Alubia Blanca en stock ✅ |
| Cœurs d'artichauts marinés | 255 g | Alcachofas congeladas en stock ✅ |
| Tahini | 80 ml (⅓ cup) | |
| Huile d'olive | 2 tbsp | |
| Citron | 1 | Zeste ½ + jus entier |
| Eau | 60 ml | Pour ajuster la texture |
| Aneth ou persil frais | à goût | |
| Sel, poivre | à goût | |
| **Topping** | | |
| Tomates cerises | 1 poignée | Rôties au four |
| Nori (algue) | à goût | Optionnel |
| Aneth frais | à goût | |

### Méthode
1. **Tomates confites** : Préchauffer four à 190°C. Mettre les tomates cerises sur plaque avec huile d'olive, sel, poivre. Rôtir **20 min**.
2. **Hummus** : Mixer haricots blancs + artichauts + tahini + huile d'olive + zeste ½ citron + jus citron + sel + poivre + eau + aneth. **1 min** jusqu'à texture crémeuse.
3. Verser dans un bol, lisser à la cuillère. Filet d'huile d'olive, tomates rôties par-dessus, aneth frais, nori.

---

## VERSION 2 : Hummus asperges rôties + ail confit + za'atar

### Ingrédients
| Ingrédient | Quantité | Notes |
|---|---|---|
| Pois chiches cuits | 160 g | Cistér Grão de Bico en stock ✅ |
| Asperges | 1 botte | Réserver 3–4 tiges pour le topping |
| Tahini | 80 ml (⅓ cup) | |
| Tête d'ail | 1 | Rôtie entière — utiliser 4 gousses |
| Huile d'olive | 2 tbsp | |
| Citron | 1 | Zeste + jus |
| Eau | 2 tbsp | |
| Sel, poivre | à goût | |
| **Topping** | | |
| Radis | 3 | En quartiers |
| Oignon vert | à goût | |
| Za'atar | à goût | |

### Méthode
1. **Ail rôti** : Préchauffer four à 180°C. Couper le chapeau de la tête d'ail, badigeonner d'huile, envelopper dans papier cuisson. Rôtir **25 min**.
2. **Asperges** : Sur la même plaque, mettre les asperges (sauf 3–4 tiges réservées) avec huile, sel, poivre. Rôtir **15 min**.
3. **Hummus** : Mixer asperges rôties + 4 gousses d'ail confit + pois chiches + tahini + huile d'olive + sel + poivre + zeste et jus de citron + eau. Mixer jusqu'à texture crémeuse.
4. **Topping** : Faire sauter les tiges d'asperges réservées à la poêle **3 min** jusqu'à légèrement croustillant.
5. Servir dans un bol, filet d'huile d'olive, radis en quartiers, asperges croustillantes, oignon vert, za'atar.

---

## Stratégie batch
- Préparer **les deux hummus en même temps** (four allumé une seule fois)
- Se conservent **4–5 jours au frigo** dans un tupperware hermétique
- Utilisations : dip apéro, sur toast, base de bowl, accompagnement de viande/poisson
