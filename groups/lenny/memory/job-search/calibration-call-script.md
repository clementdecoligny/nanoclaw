# Calibration call script

Per Clément's 21 Oct 2026 plan, every call (peer, recruiter, hiring manager) should cover:

- The three JSC (Job Search Council) questions: place me tomorrow / stretch / out of reach.
- Pay ranges per CMF, asked as ranges for the role, not personal pay.
- For the Ideal CMF specifically: "What would make me credible for a Principal PM role in an AI-native company?"
- Never reveal current pay or the floor.

The three JSC questions map to Conversations columns H–J (JSC Q1–Q3) — capture answers there per conversation, as usual.
